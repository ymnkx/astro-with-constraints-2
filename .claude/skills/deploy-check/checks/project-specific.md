# 案件固有チェックリスト

このファイルは案件ごとに編集して使う。deploy-checkスキル実行時、subagentがここの各項目をdistの生成物に対して検証する。

## 書き方

- 1項目 = 1つの `- [ ]` 行。**機械的に検証できる書き方**にする（「〜であること」+ 確認方法）
- 検証方法が自明でない項目は、子リストでgrepパターンや対象ファイルを添える
- 使わない項目は消してよい。このテンプレのまま実行された場合、subagentは「案件固有チェック未設定」と報告する

## チェック項目

- [ ] 開発用の文言が本番HTMLに残っていないこと
  - grep: `TODO`, `FIXME`, `ダミー`, `localhost`
- [ ] 全ページに `<title>` が設定され空でないこと
